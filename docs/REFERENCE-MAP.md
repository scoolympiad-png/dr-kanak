# Reference design and content map

Dr Dina Kulik's website (https://drdina.ca/) is the requested editorial and navigation reference. This project uses its broad pattern while presenting Dr Kanak's own identity, hospital, photographs and original parent education. It does not copy Dr Dina's source, copy, illustrations, logos, articles or private services.

| Reference experience | Dr Kanak implementation |
| --- | --- |
| Clear top navigation and secondary resource links | Blue primary header, white utility bar, mobile menu, searchable content, drop-down care/age/resource links |
| Doctor-led hero with a portrait and direct introduction | Dr Kanak's Mamta portrait on the left, qualifications and introduction on the right, visit and profile calls to action |
| Six prominent topic shortcuts | Parent library, Growing up, Vaccination, Watch & learn, Research, Your child's care |
| Latest blog and topic navigation | Six featured parent guides on the homepage, ten original guides in `/parent-resources/`, related reading, topic links and search |
| About, experts and credentials | `/about/`, clinical care pages, official hospital profile link and `/care-at-mamta/` with Mamta team photography |
| Media and research | `/media/` links to Dr Kanak's verified health talk; `/research/` links to attributable publications |
| Resource and FAQ pages | `/resources/`, age-stage guides, care areas, vaccination hub and FAQs |
| Contact and appointments | `/visit/`, persistent phone/WhatsApp/visit/care navigation, hospital booking handoff, directions and emergency contacts |
| Privacy and terms | `/privacy/`, `/consent/`, `/terms/`, `/accessibility/` |

The original Dr Kanak additions are seven age journeys from newborn to 18 years, a dedicated vaccination centre, Hindi entry-point summaries, and carefully bounded Patient OS and CRM integration interfaces. A separate `/my-child/` area explains verified guardian access and reminders, but actual records and messages require the existing private care service.

The reference website's books, newsletter, Canadian virtual care, product recommendations, team biographies and numerical claims have not been invented for Dr Kanak. A working newsletter or product catalogue needs approved content, a real service, and appropriate consent before publication. See [LAUNCH.md](LAUNCH.md) and [the Patient OS contract](../integrations/patient-os/CONTRACT.md) for operational prerequisites.
